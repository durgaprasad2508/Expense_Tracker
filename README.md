# Expense Tracker

A simple Java-based Expense Tracker application using Object-Oriented Programming (OOP).

## 🚀 Features

- Add expenses
- View all expenses
- View expenses by category
- Show total spending
- Show monthly summary
- Edit an expense
- Set a budget for a category
- Budget warning when spending exceeds the budget

## 🛠️ Technologies Used

- Java
- OOP
- ArrayList
- File Handling
- CSV
- LocalDate
- Exception Handling

## 📂 Project Structure
```
ExpenseTracker/
│
├── Expense.java          → Stores expense details
├── FileManager.java      → Handles file reading and writing
├── ExpenseTracker.java   → Main file that runs the Expense Tracker
└── README.md             → Project description and instructions
```

## How to Run

Compile the program:

```
javac Expense.java FileManager.java ExpenseTracker.java
java ExpenseTracker
```
